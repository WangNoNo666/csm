# 像素跳跃者 · Pixel Jumper

一个纯前端的 2D 房间制解谜跳跃游戏（类 *Celeste* 的关卡结构 + 传送门机制）。
零依赖、零构建，双击 `index.html` 即可开玩。

## 玩法

| 操作 | 默认按键 |
| --- | --- |
| 左右移动 | `A` / `D`（或 `←` / `→`） |
| 上下（爬梯/上抬） | `W` / `S` |
| 跳跃 | `Space` |
| 空中跳 | 落地前只能使用 **1 次** |
| 传送门 1 / 2 | `J` / `K` |
| 清除传送门 | `L` |
| 重开本关 | `R` |
| 暂停 | `Esc` |

核心规则：

- **一击必死**：碰到尖刺或掉落深渊立即重开本关，没有血量概念。
- **空中跳只有 1 次**（没有冲刺），落地后恢复。这是所有跳跃谜题的唯一解谜资源。
- **传送门**：放置两个门组成一条通道，穿过一个会从另一个出来，用于跨越高墙或长距离。
- **箱子 / 压力板**：推箱子压住压力板可以开门、消除尖刺、移动平台。
- 关卡按**房间**组织，走到房间边缘会自动切到相邻房间（无加载、无黑屏）。

## 关卡

- **官方关卡：20 关**（`src/levels.js`），难度递进，从教学到综合解谜。
- **自定义模式**：内置地图编辑器，可自由搭建房间、导出/导入 **分享码**。
- **地图大厅**：自定义地图的浏览、搜索、排序、试玩、删除；支持分享码一键复制与导入。

### 分享码

自定义地图可以生成一段纯文本分享码，形如：

```
PR1.<名称base64url>.<地图base64url>
```

实现要点（见 `src/custom.js`）：

- 地图是 30×18 的格子，每格用 3 bit 编码（空格/墙/尖刺/箱子/出生点/开关/终点）。
- 编码后做 **RLE 游程压缩**（游程长度用 2 字节小端，避免超过 255 时静默截断），
  再 **base64url** 编码，保证放进聊天窗口、论坛、URL 都不会被转义破坏。
- 官方 20 关实测：最长 535 字符，平均 364 字符，全部无损还原。

不需要任何服务器——分享码本身就是完整的存档。

## 目录结构

```
index.html          # 唯一入口：所有 UI、面板、样式
src/
  config.js         # 常量、物理参数、按键定义（KEYBINDS / ACTIONS）
  util.js           # 小工具
  input.js          # 键盘输入 + 键位录制（captureAction）
  actor.js          # 实体基类
  portal.js         # 传送门与传送判定
  player.js         # 玩家物理（定步长 60Hz）
  props.js          # 箱子、压力板、门、移动平台、尖刺
  levels.js         # 官方 20 关的关卡数据
  fx.js             # 粒子、浮动文字等表现
  audio.js          # WebAudio 合成音效（无外部资源）
  render.js         # 绘制
  game.js           # 游戏主循环、房间切换、状态机
  main.js           # 启动、菜单、暂停（window.__game 在此挂载）
  custom.js         # 自定义模式：编辑器、分享码、地图大厅
test/               # 无头测试（Node 直接跑，不需要浏览器）
```

`src/` 下的文件必须按上面顺序加载（互相有全局依赖），`index.html` 里已按序引入。

## 开发

游戏本身不需要构建。测试用 Node 直接跑：

```bash
node test/run-all.js        # 跑全部用例
node test/custom-mode.js    # 单跑某一套
```

测试用一个自制的 DOM stub 把 `src/*.js` 拉进 Node 环境里跑，覆盖：

| 套件 | 覆盖内容 |
| --- | --- |
| 关卡几何校验 | 每关的墙/尖刺/出生点/终点是否合法 |
| 物理与传送门 | 定步长物理、传送门出入口判定 |
| 集成与渲染 | 主循环、房间切换、绘制不报错 |
| 关卡可达性 | 出生点能否走到房间出口 |
| 端到端玩法 | 模拟输入通关 |
| 关卡流程推进 | 20 关顺序推进 |
| 关卡可玩性 | 每关是否有解、是否存在卡死点 |
| 自定义模式 | 编辑器操作、键位面板与录制状态机 |
| 分享码与地图大厅 | 编解码往返、非法码拒绝 |
| 本轮修复回归 | 历史 bug 的定点回归 |
| 难度守卫 7B | 难度曲线守卫 |
| 交付验收 | 汇总验收 |

当前基线：**1360 项全通过**。

## 浏览器

纯 Canvas 2D + 原生 JS，无框架。桌面端 Chrome / Edge / Firefox 均可。
音效用 WebAudio 实时合成，不需要任何音频文件。
